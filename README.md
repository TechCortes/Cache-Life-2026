**Arts & Entertainment Agency** — New York City

Private event production, cultural programming, and digital content creation.

## Project Structure

```
src/
├── assets/            # Images and brand assets
├── components/
│   ├── ui/            # Reusable UI primitives (shadcn)
│   ├── Layout.tsx     # Page layout wrapper
│   ├── Navbar.tsx     # Navigation bar
│   ├── Footer.tsx     # Site footer
│   └── StarryBackground.tsx  # Animated background
├── hooks/             # Custom React hooks
├── lib/               # Utilities
├── pages/             # Route pages
│   ├── Index.tsx      # Home — What We Do
│   ├── Media.tsx      # Portfolio gallery
│   ├── WhatsHappening.tsx  # Upcoming events
│   ├── Press.tsx      # Press mentions
│   └── NotFound.tsx   # 404
├── App.tsx            # Router & providers
├── index.css          # Design tokens & global styles
└── main.tsx           # Entry point
```

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router

## Development

```bash
npm install
```
